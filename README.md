# Pyhton-in-Python-Snake-Game-
Nostalgic game which we (yes WE ALL) played as a kid on the keypad phone

## 🕹️ How to Play

Use your keyboard to guide the snake around the screen:

| Key / Control | Action |
| :--- | :--- |
| **⬆️ Arrow Up / W** | Move Up |
| **⬇️ Arrow Down / S** | Move Down |
| **⬅️ Arrow Left / A** | Move Left |
| **➡️ Arrow Right / D** | Move Right |
| **Esc / Q** | Quit Game |



### Rules:
1. **Eat to Grow**: Each piece of food consumed increases your score and length.
2. **Avoid Walls**: Hitting the edge of the screen results in a Game Over.
3. **Don't Eat Yourself**: Colliding with your own body segments ends the game.
